# TSK-011 — Inizializzare il submodule code_repos/llm_wiki, in sola lettura, per i dossier di EP-004

## Context
I dossier di EP-004 (TSK-012, TSK-014, TSK-016, TSK-018, TSK-020) sono scritti da `repo-sync` per sola lettura del **sorgente**: per ogni rischio servono file e simboli letti. Il submodule `code_repos/llm_wiki` non è inizializzato (cartella vuota): senza il sorgente `repo-sync` non può leggere nulla e gli esiti sarebbero ricopiati dai raw già ingeriti, cioè dalle stesse deduzioni che EP-004 deve verificare. Questo TSK è il **prerequisito comune** a tutte le verifiche di EP-004; sta sotto US-025 perché è la prima storia dell'epica a servirsene, ma sblocca anche US-026, US-027, US-029, US-030 (e in seguito US-028, US-031, US-032). [^src: management/kanban/EP-004-verifica-rischi-di-persistenza/US-025-rischio-chat-cancellate/US-025.md §Acceptance Criteria] [^src: management/kanban/EP-004-verifica-rischi-di-persistenza/EP-004.md §Obiettivo]

## Technical Specs
- **Consumer:** `human` (`routing.infra: human`): richiede rete e checkout, che nessun agente di questa factory fa.
- **Sola lettura.** Il checkout è nel working tree della factory; nessuna scrittura, commit o branch nel repository del cliente (`suppress_ai_traces: true`). Nessuna esecuzione dell'applicazione né build (Q_003).
- Commit atteso: `e08cfce` (branch `develop`, v0.6.13), lo stesso dei raw già ingeriti. Se il gitlink punta ad altro commit, fermarsi e chiedere: i dossier devono citare lo stesso commit dei raw.
- La rete esce dal proxy dell'ambiente; se il clone fallisce vale `/root/.ccr/README.md`, non si disattiva la verifica TLS.

## Implementation Steps
1. `git submodule status code_repos/llm_wiki` e riportare lo SHA registrato.
2. `git submodule update --init code_repos/llm_wiki` (senza `--remote`: non si aggiorna il pin).
3. Verificare `git -C code_repos/llm_wiki log -1 --format=%h` uguale a `e08cfce`.
4. Verificare `git -C code_repos/llm_wiki status --short` vuoto.
5. Verificare con `git status --short` della factory che il pin del submodule non risulta modificato.

## Definition of Done
- [x] `git -C code_repos/llm_wiki log -1 --format=%h` → `e08cfce` (comando ed esito riportati).
- [x] `git -C code_repos/llm_wiki status --short` vuoto.
- [x] `git status --short` della factory: il gitlink del submodule invariato.
- [x] Nessun file del cliente modificato, nessun programma del cliente eseguito.
