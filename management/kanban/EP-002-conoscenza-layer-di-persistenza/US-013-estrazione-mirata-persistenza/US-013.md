# US-013 — Estrarre il codice di persistenza non letto

## Descrizione
Come product owner del layer di persistenza, voglio una nuova estrazione del repository di codice mirata ai file che incidono sulla persistenza e che non sono stati letti, affinché le storie successive (US-014..US-017) chiudano i gap con una fonte invece di assunzioni.

## Business Rules
- Il perimetro è dato dai gap `llm-wiki-persistenza-codice-non-letto` e `llm-wiki-file-citati-non-verificati`; la sovrapposizione con `llm-wiki-codice-non-letto` si limita ai file elencati nei due gap di persistenza.
- Nessun valore di segreto o credenziale è copiato nell'estrazione: solo nomi di campo.
- Il repository di codice è di un cliente con politica anti-traccia AI: l'estrazione è in sola lettura e non produce commit nel repository del cliente.
- L'estrazione dichiara commit, ramo e numero di file letti; un file non letto resta dichiarato non letto.

- [x] Nell'estrazione non compare alcun valore di segreto, token o credenziale; l'esito del controllo segreti è riportato. (TSK-002 §Chiusura, AC3; TSK-003 §Chiusura, AC3; TSK-004 §Chiusura, AC3; TSK-005 §Chiusura, AC3)
