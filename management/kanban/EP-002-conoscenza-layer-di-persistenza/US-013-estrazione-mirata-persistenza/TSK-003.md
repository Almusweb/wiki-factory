# TSK-003 — Estrazione repo-sync, fetta B: scritture, sincronizzazione file, log e index, file citati non verificati

## Context
Seconda delle tre fette dell'estrazione di US-013. Copre l'ambito di US-015 (scrittura generica di file lato frontend e backend, sincronizzazione e osservazione dei file, persistenza della coda di dedup e del lint, scritture delle cache di ingest e delle didascalie, e i file e cartelle citati nei commenti e non verificati) e di US-017 (formato del log e logica di aggiornamento dell'indice del progetto wiki). [^src: management/kanban/EP-002-conoscenza-layer-di-persistenza/US-015-atomicita-scritture-e-sync-file/US-015.md §Business Rules] [^src: management/kanban/EP-002-conoscenza-layer-di-persistenza/US-017-formato-log-e-index-progetto/US-017.md §Business Rules]

## Technical Specs
- **Consumer:** `human`, override esplicito di `routing.docs: agent` (decisione D1, confermata dall'utente il 2026-11-20). Ruolo Sync `repo-sync` con `/repo-sync` e STOP di Fase 4. Un TSK `docs` agentico si risolverebbe sul repository del cliente.
- **Target:** `llm_wiki`, **sola lettura**; nessun commit nel repository del cliente.
- **Perimetro:** file dei gap `llm-wiki-persistenza-codice-non-letto`, `llm-wiki-file-citati-non-verificati` e `llm-wiki-log-index-formato` pertinenti a US-015 e US-017. [^src: wiki/gaps.md §2026-11-20 17:06 — llm-wiki-file-citati-non-verificati] [^src: wiki/gaps.md §2026-11-20 17:06 — llm-wiki-log-index-formato]
- **Output:** `raw/<data>-repo-<slug>.md` (slug distinto, per esempio `llm_wiki-persistenza-b`) e voce nel manifest.
- Per ogni file o cartella citata e non verificata si riporta se esiste come archivio (con campi) o se non esiste. Nessun valore di segreto: solo nomi di campo.

## Implementation Steps
1. Lanciare `/repo-sync` su `code_repos/llm_wiki` con l'ambito della fetta B, dopo la chiusura di TSK-002.
2. Alla Fase 4 confermare solo l'ambito della fetta B.
3. Per ogni scrittura riportare il meccanismo (file temporaneo e rinomina, oppure scrittura diretta), con riferimento al file letto.
4. Riportare il formato di una voce del log e la logica dell'indice.
5. Dichiarare commit, ramo e numero di file letti; verificare che il commit è lo stesso di TSK-002, altrimenti dichiararlo.
6. Controllare l'assenza di segreti e la non modifica del repository del cliente.

## Definition of Done
- [ ] Ogni file dell'ambito è letto o dichiarato non letto con motivo.
- [ ] Per ognuno dei quattro file e cartelle del gap dei file citati: esiste come archivio, oppure non esiste.
- [ ] Il raw dichiara commit, ramo e numero di file letti.
- [ ] Nessun valore di segreto nel raw; esito del controllo riportato.
- [ ] `git -C code_repos/llm_wiki status --short` vuoto e HEAD invariato (comandi ed esiti riportati).
- [ ] Voce nel manifest aggiunta senza sovrascrivere voci altrui.
